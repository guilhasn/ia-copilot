# Caça às Cores

> Exercício livre para a primeira mão no Copilot, com a Matriz Semáforo aplicada à sua semana real.

**Duração:** 10-12 min · individual + partilha em chat · Copilot Chat com conta institucional

## Para que serve

Este exercício treina três coisas ao mesmo tempo:

- **Primeiro toque no Copilot** — abrir, fazer login, escrever um prompt, ler o output

- **A Matriz não é teórica** — aplicá-la ao próprio prompt antes de o enviar

- **A cor não é evidente** — outras pessoas podem ler o mesmo prompt e ver cor diferente

## Como jogar

### 1. Abrir o Copilot

Em [m365.cloud.microsoft/chat](https://m365.cloud.microsoft/chat), com a conta institucional da sua IES.

### 2. Explorar prompts da sua semana

Pense em **tarefas reais** que tem para fazer esta semana — escrever um aviso, sumarizar um documento, fazer brainstorming de uma sessão, traduzir um e-mail, organizar uma agenda. Qualquer coisa.

Para cada tarefa, escreva um prompt e atribua-lhe uma cor da Matriz **antes de o enviar**:

- 🟢 **Verde** — execute à vontade

- 🟡 **Amarelo** — execute com cuidados (validar dados, não partilhar tal qual)

- 🔴 **Vermelho** — não execute com dados reais; apenas pense no prompt

- ⛔ **Nunca** — apenas pense no enunciado, para perceber a fronteira

### 3. Partilhar no chat do Zoom

Quando achar que um prompt vale a pena submeter à turma, cole no chat com a sua intuição de cor seguida de `?`:

> 🟢? *Sugere 5 ideias de programa para uma sessão de boas-vindas a novos estudantes de licenciatura, 90 min, em formato workshop.*

O `?` é importante: significa *"esta é a minha classificação — concordam?"*.

### 4. A turma reage

A turma reage à sua mensagem com emoji:

| Reação | Significa |
|---|---|
| 🟢 | Concordo verde |
| 🟡 | Eu poria amarelo |
| 🔴 | Eu poria vermelho |
| ⛔ | Eu poria nunca |
| 💡 | Aprendi algo novo aqui |

## Antes de começar

- ⚠️ **Não execute prompts amarelos e vermelhos com dados reais durante este exercício.** Para os amarelos, pense no prompt e nos cuidados. Para os vermelhos, pense no prompt mas não o envie.

- 🔒 **Use sempre o Copilot da conta institucional**, não o Copilot pessoal nem o ChatGPT pessoal.

- ⏱️ **O foco é experimentar e partilhar.** As divergências de classificação na turma são a parte mais valiosa do exercício — quanto mais, melhor.

## Exemplos para inspirar

<details markdown="1">
<summary>Um exemplo verde — execute à vontade</summary>

> *Sugere 5 ideias de programa para uma sessão de boas-vindas a novos estudantes de licenciatura, com duração de 90 minutos, em formato workshop.*

**Porquê verde:** brainstorming sobre conteúdo genérico, sem dados pessoais, sem decisão sobre pessoas.

</details>

<details markdown="1">
<summary>Um exemplo amarelo — execute com cuidados</summary>

> *Resume os assuntos pendentes da minha caixa de entrada da última semana e identifica os que precisam de resposta urgente.*

**Porquê amarelo:** o Copilot vai aceder, via Microsoft Graph, aos seus e-mails reais — informação interna, com nomes, processos, possíveis assuntos sensíveis.

Cuidados antes de avançar:

- Reveja o resumo antes de o partilhar com terceiros

- Confirme se não inclui informação reservada (reclamações, processos, dados de saúde)

- Use como apoio à sua triagem, não como registo oficial

</details>

<details markdown="1">
<summary>Um exemplo vermelho — não execute</summary>

> *Compara os meus colegas da divisão pelos seus contributos no último projeto e diz quem foi mais produtivo.*

**Porquê vermelho:** envolve juízo comparativo sobre pessoas reais identificadas, com impacto potencial em reconhecimento profissional. Mesmo que os dados estivessem todos no Microsoft 365, esta não é uma decisão a delegar à IA — é trabalho do gestor da divisão, com base em conversas, contexto e responsabilidade direta.

**Como reescrever:** se quiser usar o Copilot para apoiar este tipo de reflexão sem cair em vermelho, transforme o pedido em algo como *"ajuda-me a listar critérios objetivos para avaliar contributos numa equipa, sem nomes nem dados"*.

</details>

## Frase para levar para casa

> Um bom utilizador de IA não é apenas quem escreve bons prompts. É quem sabe parar antes de o enviar e perguntar: *de que cor é isto?*
