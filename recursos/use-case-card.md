# Use Case Card

O **Use Case Card** é uma ficha simples para avaliar e documentar um caso de uso de IA antes da sua aplicação.

## Objetivo

Ajudar o utilizador a responder a quatro perguntas:

1. O que quero fazer com IA?
2. Que dados vou usar?
3. Quem pode ser afetado?
4. O output será apenas apoio ou poderá influenciar uma decisão?

## Modelo

| Campo | Pergunta |
|---|---|
| Nome do caso de uso | O que quero fazer com IA? |
| Serviço ou área | Em que contexto será usado? |
| Dados usados | Que informação será introduzida? |
| Pessoas afetadas | Há impacto sobre trabalhadores, estudantes, candidatos ou terceiros? |
| Finalidade | Apoio à redação, análise, síntese, decisão ou comunicação? |
| Ferramenta | Copilot Chat, Word, Excel, PowerPoint, Outlook, Teams, Pages ou Studio? |
| Classificação | Verde, amarelo, vermelho ou nunca? |
| Salvaguardas | Anonimização, minimização, validação humana, autorização, revisão jurídica? |
| Output permitido | Rascunho, resumo, tabela, checklist, relatório preliminar? |
| Output proibido | Decisão, ranking, exclusão, fundamentação final automática? |
| Evidência | Prompt, output, revisão humana, data e responsável? |

## Regra essencial

> Se o output puder influenciar uma decisão sobre uma pessoa, o caso deve ser tratado como crítico.
